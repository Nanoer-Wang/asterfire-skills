# 镜像路径证据优先级

1. 用户明确提供且与目标镜像一致的路径。
2. 当前镜像版本/提交对应的 image_layout.md、镜像检查或构建日志。
3. Dockerfile 的 ENV *_HOME/ROOT/DIR、COPY/ADD 目标和构建期文件自检。
4. WORKDIR 仅作辅助，不能独立证明资源存在。

说明与 Dockerfile 冲突时先通过版本/日志或只读探针核实，修正过时材料；不能默认旧说明总是正确。无法证明路径时保留具体缺口，不凭本机目录推断。

只对镜像内稳定第三方引擎、依赖、权重和数据库建立绝对路径映射；Kit 业务模块从投递位置加载，当前任务/节点输入输出以工作目录为基准。完整流程见 [image-lifecycle.md](image-lifecycle.md)。
