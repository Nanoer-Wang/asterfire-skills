# Yunxiao Flow integration

Verified against Alibaba Cloud docs on 2026-09-17.

## Pipeline API

Current OAPI supports:

- Create pipeline: `POST .../oapi/v1/flow/.../pipelines`
- Run pipeline: `POST .../pipelines/{pipelineId}/runs`
- Get run: `GET .../pipelines/{pipelineId}/runs/{pipelineRunId}`

Auth header: `x-yunxiao-token`.

Docs:
- https://help.aliyun.com/zh/yunxiao/developer-reference/createpipeline-create-pipeline
- https://help.aliyun.com/zh/yunxiao/developer-reference/createpipelinerun
- https://help.aliyun.com/zh/yunxiao/developer-reference/getpipelinerun

The API endpoint domain differs by Yunxiao deployment/edition, so `yunxiao.domain` is explicit configuration and is not guessed.

## Build clusters

This Skill applies the user's fixed routing policy:

- external internet needed -> `public/cn-hongkong`
- no external internet needed -> `public/cn-beijing`

Official YAML identifiers:

- Beijing: `public/cn-beijing`
- Hangzhou: `public/cn-hangzhou`
- China Hong Kong: `public/cn-hongkong`

Default build platform: `Linux/amd64`.

Docs:
- https://help.aliyun.com/zh/yunxiao/user-guide/pipelined-task-jobs
- https://help.aliyun.com/zh/yunxiao/user-guide/build-a-cluster

## Codeup source

YAML pipelines support `sources.<id>.type: codeup`, `endpoint`, branch and service connection.

The service-connection listing API returns both a public `uuid` and an internal numeric `id`.
YAML source and build-step fields require the public UUID. The numeric internal ID is returned
in run metadata but fails YAML validation when supplied as `serviceConnection`.

## ACR build step

For ACR Enterprise Edition, Flow's generated YAML uses `DockerBuildPushACREE`, not
the generic `ACRDockerBuild` step. Required fields include `serviceConnection`,
`region`, `instance`, `namespace`, `dockerRegistry` (the repository name),
`dockerTag`, `dockerfilePath`, and optionally `cacheType`. Copy `instance` exactly
from YAML generated by the Flow UI after selecting the enterprise instance; do not
infer it from the Registry hostname or display name.

Use the generic `ACRDockerBuild` branch only for non-enterprise configurations.

Docs:
- https://help.aliyun.com/zh/yunxiao/user-guide/analysis-of-key-concepts-of-pipeline
- https://help.aliyun.com/zh/yunxiao/user-guide/build-image-and-push-to-acr

## Important ACR Enterprise networking note

When Flow public build clusters push to ACR Enterprise, ACR public access and whitelist rules must permit both Flow service IPs and the selected public build cluster egress IPs. The current Alibaba Cloud build-cluster doc lists these addresses; do not hard-code them forever—re-check before provisioning firewall rules.
